# Проект: шаблон главной для компаний автопривоза (avtoprivoz-1)

Универсальный шаблон главной страницы для компаний, которые привозят машины под заказ из Китая, Кореи и ОАЭ. Илья показывает его потенциальным клиентам как концепт их новой главной: подставил данные компании — получил демо. Первый пример заполнен под МГК Авто, следующим будет FoxAvto.

Смыслы, структура и тексты лежат в `docs/`. Читай перед работой:

@DESIGN.md
@docs/shablon-glavnaya-wireframe.md
@docs/referensy-rezume.md

Фон и логика блоков: `docs/etalon-struktura-avtoprivoz.md`. Исходная постановка задачи: `docs/PROMPT.md`.

## Стек
- Vite + чистый JS + CSS, как в соседнем проекте `whale auto2`. React, Tailwind и библиотек анимации нет. Новые зависимости и смену стека согласовывать.
- Пакетный менеджер npm. Dev-порт 4323 (4321 и 4322 заняты другими проектами).
- Шрифты лежат в проекте (`@fontsource-variable/*`), без Google Fonts.

## Команды
- `npm run dev` запуск, `npm run build` сборка, `npm run preview` проверка сборки.
- `COMPANY=foxavto npm run build` сборка под другую компанию (файл `src/companies/foxavto.js`).
- `npm run images` пересобрать фото из `media-src/` в `public/media/` (WebP двух размеров).

## Как устроено
- **Страница собирается в готовый HTML при сборке.** `vite.config.js` вызывает `src/page.js`, тот собирает блоки из `src/sections/*.js`. Заголовок и тексты видны сразу, без ожидания JS.
- **Данные компании: один файл** `src/companies/<компания>.js`. Смена компании = новый файл, компоненты не трогаем. В файле же задаются типаж, мессенджер по умолчанию и тексты сообщений.
- **Три вида значений** (`src/lib/marks.js`): обычный текст (реальный факт), `demo(…)` (цифра-пример, плашка «демо»), `ask('что')` (данных нет, вопрос для созвона).
- **Плашки «уточнить»** включаются в файле компании: `display.showAsk`. Для показа дизайна `false` (решение Ильи 14.11.2026): плашек нет, строки без данных убраны. Все вопросы ведём в `docs/utochnit.md`, при новом `ask(…)` дописывать туда.
- `src/sections/` разметка блоков (строки HTML, без DOM: файлы выполняются в Node при сборке).
- `src/client/` поведение в браузере: шапка, карусель по дуге, фильтры ленты, переворот карточки, квиз.
- `src/lib/` общее: плашки, форматы чисел, ссылки в мессенджер, иконки.
- `src/styles/` стили: `tokens.css` (все цвета, шрифты, радиусы, отступы) и по файлу на блок.
- `public/media/` фото и видео для страницы. `media-src/` исходники фото (в git не попадают) и `credits.json` с авторами и лицензиями.

## Правила работы
- Сначала план, потом код. После правок `npm run build`. Коммит после каждого утверждённого блока.
- **Тексты и структура только из `docs/shablon-glavnaya-wireframe.md`.** Заголовки и тексты не переписывать. Если текст не помещается, показать Илье место и предложить вариант.
- Новые цифры, отзывы, сроки и условия не придумывать. Нет данных: `ask(…)`.
- Блоки, которых нет в вайрфрейме, не добавлять. Блок 6 «Преимущества» не верстать без согласия Ильи.
- Стиль только из `DESIGN.md`, значения только через токены из `src/styles/tokens.css`.
- Скилл `design-taste-frontend`: вайрфрейм и `DESIGN.md` главнее скилла. Новые направления, палитру, шрифты и сетку из него не брать. Используем для проверки (`lint.mjs`, `inspect.mjs`) и критики готовых блоков; о конфликтах правил скилла с вайрфреймом сообщать Илье, а не править молча.
- Перед показом клиенту прогонять `web-design-guidelines` по изменённым файлам.
- Адаптив: 375, 768, 1280 px, плюс низкий ноутбук 1536×730 для первого экрана.
- Анимация: `~/.claude/animation-principles.md` и раздел «Движение» в `DESIGN.md`. Тяжёлый эффект один: карусель первого экрана. Учитывать `prefers-reduced-motion`.
- Страница закрыта от поиска: `noindex, nofollow` в `index.html`. Не убирать, пока это демо.
- Проекты `whale auto2` и `whale-auto` не трогать.
