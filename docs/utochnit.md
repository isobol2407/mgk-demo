# Что уточнить у МГК Авто

Вопросы для созвона. На странице плашки «уточнить» сейчас скрыты (`display.showAsk: false` в `src/companies/mgk-avto.js`), строки без данных убраны из вёрстки. Чтобы увидеть плашки на своих местах, поставить `showAsk: true` и пересобрать.
