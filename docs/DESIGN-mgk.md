# DESIGN.md — МГК Авто, фирменный стиль

Версия 1 от 16.11.2026. Основа — рекламный баннер МГК «Утильсбор: новые правила» (кобальтовый фон, лаймовый акцент).
Этот документ относится к сайту МГК («автопривоз 1»). К шаблону в стиле минимализма он не относится.

## Что берём с баннера

| Приём на баннере | Что это |
|---|---|
| Кобальтовый фон с лёгким переходом к более тёмному синему | Основной цвет бренда |
| Лаймовый цвет | Единственный акцент |
| Белый жирный заголовок, вторая строка лаймом | Двухцветный заголовок |
| Лаймовая плашка с тёмным текстом («Новости · Утильсбор») | Метка |

| Лаймовая нижняя полоса с призывом | Финальная полоса действия |

## Цвет

Значения сняты с баннера на глаз. Перед вёрсткой возьми точные цвета пипеткой с исходника или из брендбука МГК.

| Токен | Значение (примерно) | Где |
|---|---|---|
| `--blue` | `#0B2BE0` | Фон акцентных секций, ссылки и цифры на светлом |
| `--blue-deep` | `#06158F` | Тёмный край градиента, текст на лаймовом |
| `--lime` | `#C8F52E` | Акцент |
| `--white` | `#FFFFFF` | Фон светлых секций, текст на синем |
| `--ink` | `#0A0F2C` | Основной текст на светлом |
| `--ink-2` | `#5B6178` | Второстепенный текст |
| `--line` | `rgba(10,15,44,0.12)` | Линии |

Градиент синих секций: от `--blue` к `--blue-deep` по диагонали, без других цветов.

## Шрифт

Шрифт сайта не меняем: остаётся текущий шрифт проекта со всеми его размерами и начертаниями. С баннера берём только приём, а не гарнитуру: в заголовке первая строка белая, вторая лаймовая.

## Где живёт лаймовый

Правило: лаймовый отмечает деньги покупателя и главное действие. Больше ничего.

| Место | Как |
|---|---|
| Сумма экономии и выгоды | Лаймовая подложка-маркер под цифрой, текст `--blue-deep`. На синем фоне — лаймовый текст без подложки |
| Главная кнопка экрана | Лаймовая заливка, текст `--blue-deep`. Одна на экран |
| Вторая строка заголовка на синем фоне | Лаймовый текст, как на баннере |
| Плашки-метки | «до 160 л.с.», «новый», дата выдачи: лаймовая плашка, тёмный текст |
| Активный пункт фильтра | Лаймовая «таблетка» |
| Диагональная полоса | Под машиной на первом экране и под активной карточкой. Один раз на экран |
| Сегмент «Выгода» в разборе цены | Единственный лаймовый сегмент диаграммы |
| Финальная полоса | Последний экран с призывом — лаймовый на всю ширину, текст `--blue-deep` |

## Где лаймового нет

- Лаймовый текст на белом фоне: он не читается. На белом лаймовый — только заливка под тёмным текстом.
- Белый текст на лаймовом.
- Обычные ссылки, иконки, линии, фон карточек.
- Больше одной лаймовой кнопки на экран.
- Крупные лаймовые плоскости в середине страницы. Большая плоскость одна — финальная полоса.

Ориентир по площади: синий и белый делят страницу, лаймового не больше десятой части экрана.

## Формы и движение

- Диагональ — фирменный приём: наклон полосы около 12–15°, один и тот же везде.
- Плашки со скруглением 8–10 px, как на баннере.
- Машины на синем фоне — вырезанные, без фона, с мягкой тенью под колёсами.
- Маркер под суммой при появлении «прокрашивается» слева направо. Остальная анимация по общим правилам проекта.

- [ ] Контраст: белый и лаймовый на синем, `--blue-deep` на лаймовом.
- [ ] Лаймовый на телефоне при максимальной яркости: не режет ли глаз на финальной полосе.
