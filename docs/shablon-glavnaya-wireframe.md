## Как читать

- **Слот** — место, куда подставляются данные конкретной компании. В тексте слоты выделены так: `{город}`.
- **«демо»** — цифра-пример для макета. На странице у таких цифр стоит пометка «демо».
- **[уточнить]** — данных нет, это вопрос для созвона с клиентом.
- Реальные факты МГК взяты с их сайта: 300+ машин, офисы в Ижевске и Казани, возврат депозита за 3 рабочих дня, страховка груза, сверка VIN, договор для скачивания, срок 1,5–2 месяца, сотрудники в Корее и Киргизии, цена Geely Monjaro 3,98 млн ₽.

## 0. Шапка

Низкая, без скруглённых подложек у меню.

```
[лого] {Название}    Привезённые · Цена · Как работаем · Контакты    [TG][MAX]  [Написать в Telegram]
```

На телефоне: логотип, иконка мессенджера, меню-бургер. Внизу экрана закреплена кнопка «Написать в Telegram», она появляется после первого экрана.

### Карусель привезённых машин

Шесть карточек стоят по вогнутой дуге и идут по кругу. Центральная карточка крупнее и развёрнута к зрителю, соседние меньше и повёрнуты. В карточке только фото машины на выдаче. Вся информация вынесена в подпись под дугой и меняется вместе с центральной карточкой.

| Элемент | Текст или поведение |
|---|---|
| Подпись, строка 1 | Geely Monjaro, 2025 · Ижевск · 12.10.2026 |
| Подпись, строка 2 | Экономия 0,72 млн ₽ · демо |
| Кнопка | ✈ Хочу такую же |
| Ссылка | Пост о выдаче ↗ |
| Точки | По числу карточек, активная выделена |
| Управление | Перетаскивание мышью, свайп, клик по боковой карточке, стрелки на клавиатуре. После прокрутки карусель доводится до ближайшей карточки |
| Без действий пользователя | Медленно листается сама, останавливается при наведении и после первого действия |

Кнопка «Хочу такую же» открывает Telegram с сообщением: «Здравствуйте! Хочу такую же: Geely Monjaro 2025. Сколько сейчас под ключ в Ижевске?»

Данные карусели — те же сделки, что в блоке 2 (шесть последних). В блоке 1 они показаны коротко и ради впечатления, в блоке 2 — с ценами и фильтром.

### Что меняется по типажу

| Типаж | H1 | Снимки в заголовке |
|---|---|---|
| Компания без лица (МГК) | «Привезём…» | Выдачи у офиса, одно видео |
| Лицо-эксперт | «Привезу вам…» | Один из снимков — портрет руководителя |
| Экспортёр | «Привезём из {страна}, осмотр на месте» | Снимки с площадки осмотра за рубежом |

### Ограничения

- Карусель делается на CSS-трансформациях и библиотеке анимации из стека проекта, без WebGL. Это единственный тяжёлый эффект страницы.
- Заголовок появляется сразу как текст, снимки и карусель подгружаются после него.
- При `prefers-reduced-motion` карточки стоят плоским рядом, сами не листаются, снимки в заголовке без наклона при появлении.

### Телефон (375)

Заголовок в пять-шесть строк, два снимка вместо трёх. Под ним подзаголовок и кнопка на всю ширину, плашки рейтингов в одну строку. Карусель: в центре одна карточка, по краям видны куски соседних, дуга слабее, листается свайпом. Подпись и кнопка под ней.

### Проверить при вёрстке

- [ ] Заголовок из девяти слов в три строки на 1280 px и 768 px: читается ли он с тремя вставками. Если нет, оставить две.
- [ ] Узкий жирный шрифт с кириллицей: буквы Ж, Ё, Й в прописном наборе.

## 5. Подбор и контакты

**Вопрос покупателя:** а если я ещё не выбрал машину?
**Референсы:** `refs/04-modal-quiz.png` (квиз), правая карточка из `refs/03-likeavto-sdelki-filtr.png` (каталог одним сообщением).

```
┌────────────────────────────────────────┐ ┌───────────────────────┐
│ H2: Не выбрали машину?                 │ │ КАТАЛОГ ОДНИМ         │
│ Какой бюджет под ключ?                 │ │ СООБЩЕНИЕМ            │
│ [до 2] [2–3] [3–5] [от 5] [не знаю]    │ │ [✈ Получить в Telegram]│
│ 3 вопроса · без номера телефона        │ │ [MAX] [ВКонтакте]     │
└────────────────────────────────────────┘ └───────────────────────┘
КОНТАКТЫ: адреса · телефоны · мессенджеры · отзывы на картах
```

### Тексты

**Карточка квиза**

| Элемент | Текст |
|---|---|
| H2 | Не выбрали машину? Подберём под бюджет |
| Подзаголовок | Три вопроса. В ответ пришлём 3–5 вариантов с ценой под ключ. |
| Вопрос 1 | Какой бюджет под ключ? |
| Варианты | до 2 млн · 2–3 млн · 3–5 млн · от 5 млн · Пока не знаю |
| Мелко | Номер телефона не нужен, ответим в мессенджере. |

Первый вопрос стоит прямо в блоке. Нажатие на вариант открывает модалку сразу на втором шаге. Так у модалки есть контекст: человек уже начал отвечать.

**Модалка**

| Шаг | Вопрос | Варианты |
|---|---|---|
| 1 из 3 | Какой бюджет под ключ? | (уже выбран в блоке) |
| 2 из 3 | Новая или с пробегом? | Новая · С пробегом · Не важно |
| 3 из 3 | Куда прислать подборку? | ✈ Telegram · MAX · ВКонтакте |
| Финал | Готово. Откройте чат и отправьте сообщение, подборка придёт туда. | ✈ Открыть Telegram |

Финальная кнопка открывает мессенджер с сообщением: «Здравствуйте! Подберите машину: бюджет 2–3 млн, новая.»

Чего в модалке нет: счётчика машин, чисел рядом с вариантами, ленты машин внизу, длинных пояснений. Вместо счётчика работает строка «Шаг 2 из 3»: она показывает, что процесс короткий и конечный.

**Карточка «Каталог одним сообщением»**

| Элемент | Текст |
|---|---|
| Заголовок | Каталог машин до 160 л.с. — одним сообщением |
| Текст | Модели с ценами под ключ. На них действует льготный утильсбор. |
| Кнопка 1 | ✈ Получить в Telegram |
| Кнопки 2 и 3 | MAX · ВКонтакте |

**Контакты**

| Элемент | Текст |
|---|---|
| Заголовок | Приезжайте в офис или напишите |
| Ижевск | ул. Карла Маркса, 308 к1 · {телефон} |
| Казань | ул. Тази Гиззата, 26/1 · {телефон} |
| Мессенджеры | Telegram · MAX · ВКонтакте · Авито |
| Отзывы | Яндекс.Карты ↗ · Авито ↗ |

### Телефон (375)

Порядок: квиз → каталог → контакты. Варианты бюджета в два столбца. Модалка открывается на весь экран.
